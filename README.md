# mecaniQA-belo-horizonte

## Contexto

A MecâniQA Tech fornece um sistema SaaS de gestão e diagnóstico automotivo para oficinas mecânicas. A aplicação utiliza Java no back-end, MySQL para os dados transacionais e Redis para armazenamento de dados em alta velocidade.

O projeto tem como objetivo modernizar a infraestrutura atual, que apresenta dificuldades de escalabilidade e esgotamento de recursos, migrando para uma solução mais resiliente e conteinerizada com Docker, Docker Compose, Terraform e Kubernetes.
